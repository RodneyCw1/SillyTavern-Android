# 1.1.4 重启保存与 LocalDream 兼容修复

日期：2026-10-07。应用 versionCode 7，SillyTavern 核心仍为 1.19.0；酒馆助手 4.11.2 的 Android 补丁编号为 2。

## 修复

- 工坊下载记录和角色脚本版本：酒馆助手保存时只替换对应扩展字段，避免整卡重写清空其他数据。保存快照依次提交，后端将读、改、写串行执行，避免较慢的旧请求覆盖新数据。
- 脚本数据与缓存共享对象时，内存相等不再被当作已保存。写盘失败明确返回失败并提示，后续保存可以重试。导出时临时清理的数据也能准确恢复到磁盘。
- 元数据保存直接保留 PNG 图片数据，减少手机上解码整张头像的内存开销。更新前后的头像像素数据一致。
- 重启、退出按钮先等待酒馆的延迟保存、酒馆助手保存队列和当前保存请求结束；失败时取消该次退出或重启。
- 启动保留现有后端配置并补充缺少的默认项。应用必需的监听、私有数据目录及认证设置仍由宿主决定。
- 用户通过 Git 安装或更新的插件保留原分支，即使上游版本号相同或缺少 Android 补丁编号，也不会被 APK 内置副本替换。
- LocalDream 提供固定的同源转发接口，仅访问本机 `127.0.0.1:8081` 的 `/health` 和 `/generate`，不转发酒馆的 cookie、CSRF 或宿主令牌。
- 配套生图脚本 7.5.1 增加消息接收事件，恢复上次中断留下的 PENDING/ERROR 状态，防止同一会话中的流式事件重复排队；显示服务和模型错误。支持分片、CRLF、末尾没有换行的 SSE，以及 JPEG/PNG 和旧版 raw 图片结果。

## 手机使用

1. 使用 `releases/SillyTavern-Standalone-1.1.4-release.apk` 覆盖安装原正式版，保留应用数据。不要卸载原应用或重新导入整份迁移包。
2. 在酒馆助手中导入 `compatibility/LocalDream/酒馆助手脚本-手机本地生图v7.5.1.json`，替换原 7.5。两版脚本 ID 相同，不要让两份生图脚本同时运行。原先的三个正则可以继续使用，本次未改动它们。
3. 保持 LocalDream 2.8.1 的模型生图页面或设备连接主机模式运行，再返回酒馆聊天。自动生图需要模型回复中包含 `<local_img>提示词</local_img>`；正则只处理显示，不会替模型生成提示词标签。
4. 之前已经被回滚并丢失的工坊记录或脚本更新需要重新下载、更新一次。修复不会凭空恢复已丢失的数据。

LocalDream 2.8.1 本体 APK 未改动。接口核对来源：[官方 2.8.1 后端源码](https://github.com/xororz/local-dream/blob/v2.8.1/app/src/main/cpp/src/main.cpp)。
